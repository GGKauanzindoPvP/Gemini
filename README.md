# Gota a Gota — Landing Page

Tema escolhido: **Uso consciente da água**, um dos temas obrigatórios do roteiro da atividade.

## Arquivos
- `index.html`: estrutura da página com HTML5 semântico, menu por âncoras, imagem, vídeo incorporado, tabela e rodapé.
- `style.css`: estilos com Flexbox, cores, tipografia, sombras, bordas, `position`, efeitos `:hover` e media queries para telas menores.

## Conformidade com a atividade
- HTML5 e CSS3 puros.
- Sem JavaScript, frameworks, bibliotecas externas de CSS ou animações `@keyframes`.
- Os links do menu apontam para seções da mesma página.
- A tabela usa dados descritivos de hábitos, sem inventar números de consumo.
- A imagem e o vídeo usam recursos externos; é necessário ter conexão com a internet para carregá-los.

## Antes de entregar
1. Abra `index.html` no navegador e teste todos os links e o vídeo.
2. Confirme se a incorporação do vídeo continua disponível na sua rede. Se não abrir, troque o identificador do vídeo no `src` do `iframe` por um vídeo educativo validado pela equipe.
3. Substitua o e-mail de exemplo `contato@gotaagota.example` por um contato real ou ajuste o botão.
4. Publique `index.html`, `style.css` e eventuais imagens locais na raiz de um repositório público e ative o GitHub Pages em Settings > Pages.
5. O roteiro também pede comparar o mesmo prompt em pelo menos duas IAs diferentes e relatar as adaptações feitas pela equipe.

## Prompt-base para registrar no relatório
“Crie uma landing page informativa sobre uso consciente da água usando somente HTML5 e CSS3 puros. Não use JavaScript, frameworks, bibliotecas externas ou `@keyframes`. Inclua header com menu por âncoras, hero com imagem e chamada para ação, seções informativas, cards com efeitos `:hover`, tabela HTML, vídeo incorporado, rodapé e layout responsivo usando Flexbox. Use HTML semântico, sombras, bordas e cores harmoniosas.”
