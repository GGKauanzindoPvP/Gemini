# Landing Page: Uso Consciente da Água 💧

Projeto desenvolvido para a disciplina de **Programação Web 1** do **Instituto Federal da Bahia (IFBA) - Campus Ilhéus**, sob orientação do Prof. Regilan Meira.

## 📌 Sobre o Projeto

O objetivo deste projeto é construir uma Landing Page informativa focada na conscientização sobre o **Uso Consciente da Água**, utilizando estritamente conceitos básicos de **HTML5** e **CSS3** puros estudados em sala de aula, integrando o uso reflexivo e crítico de ferramentas de IA Generativa.

---

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**: Estruturação utilizando tags semânticas (`<header>`, `<section>`, `<footer>`, `<div>`), tabelas (`<table>`), listas (`<ul>`, `<li>`), e mídia (`<iframe>`, `<audio>`).
- **CSS3 Puro**: Estilização com `display: flex`, propriedades de sombras (`box-shadow`, `text-shadow`), bordas (`border-radius`), posicionamento (`relative`, `sticky`), e efeitos pseudo-classes (`:hover`).

> ⚠️ **Restrições de Código Seguidas:**
> - Sem JavaScript
> - Sem bibliotecas ou frameworks externos (ex: Bootstrap, Tailwind)
> - Sem animações CSS com `@keyframes`
> - Sem o uso de `thead`, `tbody`, `z-index`, `list-style`, `linear-gradient`, `overflow` ou `overflow-x`.

## 🌐 Publicação no GitHub Pages

1. Crie um repositório público no GitHub com o nome do projeto (ex: `uso-consciente-agua`).
2. Adicione os arquivos `index.html`, `style.css` e `README.md` na raiz do repositório.
3. Vá para **Settings** (Configurações) > **Pages**.
4. Em **Build and deployment > Branch**, selecione a branch `main` (ou `master`) e mantenha a pasta como `/(root)`.
5. Clique em **Save**. Seu site estará disponível no link gerado.
